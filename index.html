Brisanje keša pregledača ne briše centralnu evidenciju. Disk F je dodatna rezervna kopija.

Kako se koristi i šta znače Excel, CSV i JSON?
  1. Radnik izabere svoje ime, unese postojeći PIN, datum, status i vreme, pa sačuva unos u centralnu bazu.
  2. U „Moja kartica” vidi tekući mesec, prethodni mesec i raniju istoriju.
  3. Admin bira mesec i dobija tabelu i obračun za sve radnike.
  4. Admin jednom poveže folder F:\Aplikacija radnih sati. Dok je admin stranica otvorena, najnovija JSON kopija se automatski osvežava.
  5. Na kraju meseca kliknite Sačuvaj mesečnu evidenciju. U izabrani folder se čuva ZIP sa Excelom, CSV tabelom i JSON kopijom.
  6. CSV je jednostavna tabela bez boja i formatiranja. JSON je potpuna rezervna kopija podataka.

Važno: GitHub Pages prikazuje aplikaciju, Supabase čuva zajedničke podatke, a disk F služi kao dodatna lokalna zaštita.
